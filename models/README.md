# Bundled models

Both models come from the [OpenCV Model Zoo](https://github.com/opencv/opencv_zoo) and are included here so FaceRoll works offline with no extra downloads.

| File | Model | Task | Licence |
|---|---|---|---|
| `face_detection_yunet_2023mar.onnx` | YuNet (Wu et al., 2023) | Face detection + 5 landmarks | MIT |
| `face_recognition_sface_2021dec.onnx` | SFace (Zhong et al., 2021) | 128-d face embedding | Apache-2.0 |
